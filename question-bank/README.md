## 结构化数据与网页同步

- **[fast-track.js](./fast-track.js)** 保存 GZ Fast Track（F 系列）、HK 常规（H 系列）和 HK Fast Track（T 系列）题库，各自使用独立 ID。
- **[questions.js](./questions.js)** 是常规 ELPA 练习页面读取的题目数据文件。新增的社区题目须经维护者批准，由自动化生成 PR，不允许匿名投稿直接改动已发布数据。新增／修正题目时，优先在此维护稳定 ID、英文题干、中文说明和提示小问；页面会自动读取，不必修改 `index.html`。
- 本目录下的 Markdown 文档负责**场次、来源、回忆差异与整理说明**，不是从数据文件自动生成的副本。更新题目时应一并检查相关说明是否需要同步修订。
- **[appearances.js](./appearances.js)** 只保存经审核、有来源依据的考试场次与新增反馈；原有往年汇总或 Fast Track 练习题不凭空补录考试日期。`supplement` 不增加考试经历计数。
- **[advice.js](./advice.js)** 保存考生经验；**[taxonomy.js](./taxonomy.js)** 提供稳定分类代码及中英文标签。
- 网站按最新已收录的完整场次（学期 + 阶段）展示**当前场次题库**和**过往题库**；相同题目再次确认出现时复用原 ID。

## 怎样使用

1. 优先查看顶部最新学期题库，也可继续练习过往题库。
2. 抽到具体问题时，优先理解主问题与提示小问；不要只靠固定模板答非所问。
3. 如有新题，欢迎提交 **题目原文、中文说明、场次时间（如已知）、小问、来源及可信程度**。不清楚的部分请直接写“未记录／待核实”。

## 来源与标记

本目录以仓库现有网页题库、整理者已收到的考生分享及下方资料为基础。资料中的问题包括英文原文、考生回忆和后期英语改写，**并非每条英文句子都能证明是现场逐字题干**。

- **考生回忆**：有明确反馈来源的考试题目或场次记录；仍可能存在记忆偏差
- **资料汇总**：外部共享文档或原有题库中的汇编，年份／具体场次可能不完全明确
- **整理译文**：为方便检索而编写的英文表达或中文概括，不冒充原题
- **待核实**：缺少小问或无法独立确认来源，原样保留不确定性

## 维护规则

- 新增题前先查是否已有同主题记录，避免重复编号；确有不同问法时保留来源和差异。
- **完整的主问题**优先采用来源英文问法；原资料仅有中文时，可以提供忠于原意的自然英文练习表达，但必须在来源文档标明其属于整理表述，不能冒充现场逐字题卡。
- 对残缺题干与未记录的小问不擅自补全。备考思路可另写，但不写成“题卡原文”。
- 不含个人学号、联系方式等信息；如需修订，提交 [Issue](https://github.com/FuTseYi/HKUST-ELPA/issues) 或 Pull Request。

## 审核与持续更新

新题通过站内表单进入公开 GitHub Issues，**未经审核不得自动入库**。只有仓库维护者添加 `submission:approved` 标签，自动化才会准备数据更新 PR；该 PR 仍需要人工复核与合并。详见 [审核维护说明](./MODERATION.md)。
