# HKUST-ELPA

**An unofficial ELPA speaking preparation resource for HKUST students.**  
HKUST-ELPA 是学生维护的非官方 ELPA 备考资源。目前内容以香港科技大学（广州）的考生反馈和考试经验为主，未来可逐步扩展至香港本部及其他校区。

本项目汇集公开分享的题目、考生回忆与备考经验，提供题目检索、模拟练习和个人学习记录功能，希望帮助同学们更高效地准备 ELPA，并让资料能够持续更新与传承。

> [!IMPORTANT]
> 本项目由学生自主整理，**不代表香港科技大学或其任何校区的官方立场**。题目、流程和考生反馈可能因年份、批次或考场而异；请以学校当期通知与现场要求为准。除非有明确依据，不将考生回忆题标注为“官方题库”或“必考真题”。

## 网站访问

- **[Vercel · 主要访问入口](https://hkust-elpa.vercel.app/)**：独立域名入口。
- **[GitHub Pages · 备用入口](https://futseyi.github.io/HKUST-ELPA/)**：与 Vercel 使用同一 GitHub 仓库。
- 两个域名都通过独立校验的 Cloudflare Turnstile 向同一个 GitHub Issues 审核队列匿名投稿；只有维护者批准并合并相应更新 PR，题目才进入正式题库。
- **学习记录不会自动跨域同步**：练习进度与笔记保存在各自域名的浏览器存储中，切换入口前可用「备份／恢复」迁移。

## 快速开始

- **[独立题库 · Question Bank](./question-bank/README.md)**：保留**往年题库**与**社区反馈题库（始于 2026 Fall）**，保留提示小问，必要时简要标注回忆不完整的信息。
- **[网站首页](https://futseyi.github.io/HKUST-ELPA/)**：网站导航与功能概览。
- **[考试指南](https://futseyi.github.io/HKUST-ELPA/guide.html)**：常见流程与 FAQ。
- **[题库练习](https://futseyi.github.io/HKUST-ELPA/practice.html)**：两组题库、关键词与状态筛选、每页 8 题、计时与个人笔记。
- **[资料来源](https://futseyi.github.io/HKUST-ELPA/sources.html)**：资料分享链接与贡献说明。
- **页面结构**：多页面静态网站（`index.html`、`guide.html`、`practice.html`、`sources.html`），共享蓝黄导航样式见 `site.css`。
- **备考建议**：先了解当期考试流程，再按话题分类准备；练习时优先用自己的真实经历组织答案，而不是单纯背诵范文。

### 题目维护方式

`practice.html` 从 [`question-bank/questions.js`](./question-bank/questions.js) 加载结构化题目数据。题目、中文释义与提示小问请优先在该文件更新，并同步检查对应的[来源与场次文档](./question-bank/README.md)；无需改动页面 HTML 的功能代码。页面统一展示往年题库与持续更新的社区反馈题库，内部编号用于准确关联题目与个人学习记录。

### 学习记录、备份与恢复

- **默认自动保存至当前浏览器**：进度和个人笔记不需要登录，也不会因没有文件夹权限而在刷新后丢失；但清理浏览器数据、无痕模式或更换设备仍可能导致本地数据不可用。
- **⬇ 备份 / ⬆ 恢复**：可将学习记录下载为 JSON 文件，日后在同一设备或另一设备的练习页面中恢复。导出全部笔记为 Markdown 的功能也继续保留。
- **📂 可选关联文件夹**：支持的浏览器可另外关联 `elpa_data.json`；“同步文件”开关只影响该文件夹的自动写入，不影响浏览器内的自动保存。若所选文件夹已存在 JSON，会先征求导入确认。
- **保护隐私**：记录保留在个人浏览器和自行保存的文件中。**不要将个人笔记或含个人信息的备份提交到公共仓库**。

> 首批收录 **25 道往年题**与 **12 道 2026 Fall 反馈题**；社区投稿收录后网站会动态显示最新总数。近似问题在必要时保留不同问法，以便针对性练习。

## 题目整理原则

本项目采用**站内结构化整理 + 原始资料链接**的方式维护内容：

1. **按来源标注**：区分考生亲历、转述反馈与备考改写，不将来源不明的题目包装成已核实真题。
2. **去重但保留差异**：重复话题合并整理，不同场次的提问方式及提示小问可单独记录。
3. **准确优先**：对不完整或不确定的小问明确标注“回忆版本／待核实”，不擅自补写为原题。
4. **尊重原作者**：外部文档、笔记及他人整理成果优先链接和注明出处；全文转载需获得相应授权。
