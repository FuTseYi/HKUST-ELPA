# HKUST(GZ) ELPA

**An unofficial ELPA speaking preparation resource for HKUST(GZ) students.**  
香港科技大学（广州）ELPA 英语口语考试非官方备考资料整理与练习工具。

本项目汇集公开分享的题目、考生回忆与备考经验，提供题目检索、模拟练习和个人学习记录功能，希望帮助同学们更高效地准备 ELPA，并让资料能够持续更新与传承。

> [!IMPORTANT]
> 本项目由学生自主整理，**不代表 HKUST(GZ) 官方立场**。题目、流程和考生反馈可能因年份、批次或考场而异；请以学校当期通知与现场要求为准。除非有明确依据，不将考生回忆题标注为“官方题库”或“必考真题”。

## 快速开始

- **[独立题库 · Question Bank](./question-bank/README.md)**：按 2026 Fall 场次与往年题目分类整理，附提示小问、来源与不确定性说明。
- **[进入 ELPA 练习页面](https://futseyi.github.io/HKUST-GZ-ELPA/)**：浏览题目、搜索关键词、使用计时器与随机抽题。
- **[查看网页源文件](./index.html)**：本项目采用单页 HTML 页面，可下载仓库后直接在浏览器中打开 `index.html`。
- **备考建议**：先了解当期考试流程，再按话题分类准备；练习时优先用自己的真实经历组织答案，而不是单纯背诵范文。

### 题目维护方式

网页从 [`question-bank/questions.js`](./question-bank/questions.js) 加载结构化题目数据。题目、中文释义与提示小问请优先在该文件更新，并同步检查对应的[来源与场次文档](./question-bank/README.md)；无需改动页面 HTML 的功能代码。保留既有题目 ID，避免历史学习进度错位。

### 学习记录、备份与恢复

- **默认自动保存至当前浏览器**：进度和个人笔记不需要登录，也不会因没有文件夹权限而在刷新后丢失；但清理浏览器数据、无痕模式或更换设备仍可能导致本地数据不可用。
- **⬇ 备份 / ⬆ 恢复**：可将学习记录下载为 JSON 文件，日后在同一设备或另一设备的练习页面中恢复。导出全部笔记为 Markdown 的功能也继续保留。
- **📂 可选关联文件夹**：支持的浏览器可另外关联 `elpa_data.json`；“同步文件”开关只影响该文件夹的自动写入，不影响浏览器内的自动保存。若所选文件夹已存在 JSON，会先征求导入确认。
- **保护隐私**：记录保留在个人浏览器和自行保存的文件中。**不要将个人笔记或含个人信息的备份提交到公共仓库**。

> 提示：页面展示的是“题目记录”数量，来自不同年份的近似／重复主题可能分别保留，以便追踪不同资料来源，而非去重后的唯一题目数。

## 题目整理原则

本项目采用**站内结构化整理 + 原始资料链接**的方式维护内容：

1. **按来源标注**：区分考生亲历、转述反馈与备考改写，不将来源不明的题目包装成已核实真题。
2. **去重但保留差异**：重复话题合并整理，不同场次的提问方式及提示小问可单独记录。
3. **准确优先**：对不完整或不确定的小问明确标注“回忆版本／待核实”，不擅自补写为原题。
4. **尊重原作者**：外部文档、笔记及他人整理成果优先链接和注明出处；全文转载需获得相应授权。
