01 / 考试指南

先了解流程，再决定怎么准备

考试指南将常规 ELPA 与 Fast Track 分开展示。你可以查看线下小组口试的主要环节，或了解 Fast Track 的申请、准备及视频录制流程，并参考已整理的备考经验。

按考试类型切换：不用在两套不同流程中反复寻找信息。

资料可追溯：学校官方说明和学生经验分别收录在资料来源页。

02 / 结构化题库

按自己的考试情况，快速找到想练的题

题库支持选择 GZ / HK 校区及常规 ELPA / Fast Track 类型，并结合考试场次、关键词和练习状态筛选。已收录的较新场次与过往题目分开展示，方便集中准备或回顾旧题。

主问题 + 提示小问：英文题干为主，需要时再展开中文释义、相似问法与相关小问。

持续整理的反馈：考生补充的提问差异与出现记录可辅助理解题目，但不是官方抽题概率。

03 / 模拟口语

从“看过题目”，到真正开口回答

练习工具可以从当前筛选结果中随机抽取题目，减少只练熟悉话题的情况。你可以按模拟考试的准备和作答阶段计时，也可以单独使用倒计时或正向计时训练表达。

抽题与计时分开：随机抽到题目后，由你决定何时开始计时。

自主调整节奏：支持开始、暂停和重置，适合正式模拟与日常练习。

04 / 学习记录

把准备过程变成可以持续复盘的记录

每道题都能标记为“未练 / 练习中 / 已掌握”，主问题及提示小问可分别记录答案思路。笔记支持 Markdown 编辑与预览，方便反复修改，而不只是简单地勾选已完成。

自动保存：学习状态和笔记默认保存在当前浏览器，无需注册账号。

随时备份：可导出 JSON 并恢复到其他设备，也支持将笔记导出为 Markdown。

请留意：不同设备、浏览器及 Vercel / GitHub Pages 域名之间不会自动同步记录，切换前建议先下载备份。
